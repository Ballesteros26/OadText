# Should You Consider Using this Setup?

There are already enough well maintained and field-tested game engines one can use to create games. Even though I personally like the setup because it is obviously based on my preferences, I would highly advice to use one of the _proper_ engines if you want to focus on creating a game instead.

## Then Who is this Documentation for?

The documentation is written for my future self and people who also like to experiment with some custom setup and want to see if they maybe find some new ideas here.
