## Code Structure

The actual code of the game is contained in the `src` folder. The rest is mostly boilerplate. If there is a `screenshots` folder it contains screenshots I made during development.

## How to compile

Install [Node.js](https://nodejs.org/), then run:

    npm install
    npm build

This creates a `dist` folder containing the compiled game. Alternatively you can run

    npm start

to compile dev-builds on file changes and to start a local server at `localhost:8080`.
